# /improve-claude-md

Audit and rewrite the project's `CLAUDE.md` using `<important if>` conditional blocks to prevent context pollution and instruction degradation.

## Instructions
1. Invoke and follow the guidelines in the `improve-claude-md` skill.
2. Read the existing `CLAUDE.md` and assess rule complexity, structure, and scope.
3. Categorize instructions into unconditional core rules vs. task-specific conditional rules wrapped in `<important if="condition">` blocks.
4. Verify that commands, conventions, and style constraints remain clear and concise.
