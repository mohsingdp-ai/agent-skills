# Feature Development Skill

A structured, 7-phase workflow for building new features systematically rather than jumping directly into editing code.

## 7-Phase Feature Lifecycle

1. **Phase 1: Discovery**
   - Understand the intent, problem definition, user needs, and hard constraints.
2. **Phase 2: Codebase Exploration**
   - Explore existing codebase patterns, similar implementations, shared utilities, and dependencies.
3. **Phase 3: Clarifying Questions**
   - Identify edge cases, ambiguous behaviors, and UX gaps. Formulate concrete questions before writing code.
4. **Phase 4: Architecture Design**
   - Design component interfaces, data flows, state boundaries, and migration steps.
5. **Phase 5: Implementation Plan**
   - Break implementation into small, atomic, verifiable steps.
6. **Phase 6: Execution & Testing**
   - Implement tasks sequentially. Run targeted tests, linters, and type checkers at every step.
7. **Phase 7: Quality Review**
   - Verify feature against initial requirements, check edge cases, and ensure clean architecture.
